The name
The approved file says Jacob Skog. SEL's own spelling is Jacob Skaug. The dictionary entry caught it, and the surname in the speaker label is the one thing we fixed by hand in the caption editor.
The model number
Both the approved file and the raw output write SEL 2414. The dictionary enforces SEL-2414, the way SEL writes it on every product page.
The audio cues
The approved file starts straight on the first word. The enhanced track opens and closes with [upbeat music], which is what an SDH viewer needs in order to know the music is part of the clip.

Scored on spoken words with hyphenation normalised, because SEL-2414 and SEL 2414 are the same word out loud. This is a two-and-a-half minute studio recording with one speaker reading a script, so it is the easy case for any speech engine. It is here because it is a clip SEL had already approved, and that makes it a fair starting point rather than a curated one.

Both files are in the format Brightcove accepts on import: UTF-8, comma separated, no commas inside a term, one term per line. The dictionary is 2 columns with an optional header; the glossary is a single column with no header. A term cannot appear in both.

Captions, translation and accessibility, in the video rather than beside it

Captions that survive review

Auto captions are part of the platform, not an AI Suite add-on: 94 base languages and 202 locale codes, videos from five seconds to four hours, about 1.5× the runtime to process, bulk runs up to 100 videos at a time. Line breaking is syntactic in 23 languages, so cues break on phrases rather than punctuation.

Enhanced captions add speaker attribution and audio cues such as [music], which is what makes a track usable as SDH. The caption editor gives cue-level timing, a nine-position placement grid, find and replace, and a draft-to-publish gate per track.

One video, every language

Universal Translator covers 177 locale codes, about 153 languages. Translation works on full sentences with their surrounding context rather than cue by cue, which is why the Spanish reads like Spanish and not like subtitled English.

  • Translation glossaries run one per source-to-target pair, directional, with an exact locale match. Single terms work better than phrases.
  • Custom instructions are one account-wide prompt of up to 4,000 characters for register and do-not-translate rules.
  • Metadata language views carry the title and descriptions into up to 40 languages. Tags stay in English.
  • Language Groups save a set such as es-419, pt-BR, fr-FR, ru, zh-CN and apply it in one click.

Where we are honest about the limits

  • There is no translation memory connection and none is planned. Terminology comes from glossaries per language pair, plus instructions and the caption dictionary. If you want TM on one file, export the captions, run them through your CAT and re-upload.
  • There is no character-per-second or max-characters-per-line enforcement on translated lines yet. You get syntactic line breaking, cue-level editing, and a dubbing engine that fits length to timing.
  • Metadata translation does not apply the translation glossary. On this video the caption translation honoured the SEL terms and the description translation did not, so the two read slightly differently. Worth knowing before you batch a library.
  • Metadata language views are switched on per locale in Language Settings, and this demo account has French, Russian and Chinese enabled. The Spanish and Portuguese titles on this page come from the page data, not from a stored variant. That is an admin toggle, not a platform limit.
  • Speaker names inside the caption label are not passed through the dictionary. One edit in the caption editor fixes it, and the dictionary entry is already there for the transcript body.
  • Captions and the player interface language are native. Selecting the matching audio track and localized title on a website needs a small script from your web team, which is the script running on this page.
